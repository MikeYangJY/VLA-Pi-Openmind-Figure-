# Gemini Robotics 初代：理解现场与真正控制，是两类能力

[学习入口](README.md) · [前一篇：技术路线](00_technical_lineage.md) · [原报告 PDF](../papers/deepmind/gemini_robotics.pdf) · [论文](https://arxiv.org/abs/2503.20020)

**核心大纲：问题 → ER 的两条控制路径 → VLA 架构 → 数据 → 实验。** 本篇讲 2025 年初代报告，不把后来 ER 2 的接口、数据或成绩移到这一代。

## 1. 论文要解决什么问题？

通用视觉语言模型有世界知识，但机器人不仅要认出杯子，还要按指令在变化的环境里抓稳它。报告分别增强 **ER（具身推理）** 与 **VLA（动作）**，研究它们怎样支持真实操作。

## 2. ER 可以怎样参与控制？

| 路线 | 输入与输出 | 关键区别 |
|---|---|---|
| Zero-shot 代码控制 | 给任务、观测、机器人 API 说明；模型生成调用 API 的代码；系统执行并返回反馈 | 模型负责生成程序，已有控制系统负责落实 |
| Few-shot ICL 控制 | 给示范中的观测、语言、物体／末端位姿轨迹；输出新实例的末端位姿轨迹 | 示范放在上下文，不更新参数；不是给 VLA 做梯度微调 |

ER 不只做一句话的计划：报告也展示点、框、空间关系和轨迹预测。**但能够预测一个抓取位置，与端到端 VLA 在闭环中完成灵巧抓取，证据仍然不同。** 依据 §2.2–2.3、Figures 12–13。

当前 [ER notebook 导读](04_er_notebook_walkthrough.md)可帮助理解这类接口，但其现版使用 ER 2，不能当作初代论文的完整复现代码。

## 3. VLA 怎样把观察变成动作？

初代报告 Figure 14、§3.1 明确披露 **云端 VLA 骨干 + 机器人本地动作解码器**：

    图像 + 任务指令 + 机器人自身状态
                     ↓
    云端 Gemini Robotics backbone
    （由 ER 蒸馏形成并优化延迟）
                     ↓
    本地 action decoder
                     ↓
    动作片段 → 机器人执行 → 新观测

这里的 decoder 是模型系统中的动作生成组件。论文没有把所有云端／本地中间张量和全部训练实现公开，**不能自行补成“云端输出 π0 一样的 latent，本地用同一个 flow expert 解码”**。

论文给出的骨干查询延迟低于 **160 ms**，从原始观测到低层动作片段约 **250 ms**；利用片段内多个动作，有效控制频率达到 **50 Hz**。它不是每秒跑 50 次完整云端推理。也不能用这组初代数据代表 1.5 或 2 的速度。

## 4. 怎么训练，用什么数据？

基础 Gemini 的多模态能力 → 具身推理增强 → 蒸馏／构建动作骨干并训练机器人动作能力 → 必要时对任务或新本体继续适配。

这是报告内容的阅读顺序示意，不表示公开了每个训练阶段的全部严格先后关系。

报告披露 ALOHA 2 遥操作采集持续 12 个月，含数千小时专家示范和数千类任务；同时使用网页、代码、图像／音频／视频、具身推理及视觉问答等非动作数据。**动作记录帮助学怎样动；多模态数据帮助理解目标和变化。** 完整数据配比与动作头损失未公开。依据 §3.1。

## 5. 实验应该怎样读？

| 实验 | 它回答什么 | 别扩大成什么 |
|---|---|---|
| ERQA：400 道视觉选择题 | 模型能否理解空间、轨迹、动作和状态等 | 真实机器人操作成功率 |
| ER 代码控制与 ICL，Tables 5–6 | 几个示范如何帮助特定控制任务 | 所有家务或任意机器人的总能力 |
| VLA 短任务，§3.2 | 多任务模型能否完成不同灵巧操作 | 全部任务都是从未训练过；该组从数据中抽取 20 项任务 |
| 语言跟随与泛化，§3.3–3.4 | 换语言、对象、背景等条件时表现怎样 | 任意新运动技能都可以零样本完成 |
| 专门化与适配，§4 | 进一步训练后能否解决高难度任务／新身体 | 所有展示都来自同一模型、无额外训练 |

ICL 的实机 25%→65% 及测试规模、控制方式变化见[专题原表解释](06_icl_world_models_and_evaluation.md)。动作模型实验中的 π0 对照是作者在其数据混合上训练的 **π0 re-implement**，不能当作直接测试 PI 所有官方 checkpoint。
