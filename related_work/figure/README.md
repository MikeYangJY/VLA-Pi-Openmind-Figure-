## 用同一条逻辑串起来

**Helix：语义与动作怎样连接 → Helix 02：怎样让全身一起行动 → Index：从哪里获得更广经验 → Helix 2.5：这些经验能否迁移到新家庭。**

这是一条学习线索；Index是数据体系，不是另一个动作模型。各版本未公开的参数和训练细节仍按原笔记标注。
