# PI 访谈提纲｜60 分钟，12 个必问

[首页](../../README.md) · [PI 学习入口](README.md) · [访谈方法](../INTERVIEW_PREP.md)

**12 个必问对应客户的全部 12 项需求。** 每题先问粗体主问，答漏的内容再按“补齐”追问。主问和补齐项共同构成必问范围；已经回答过的直接记录，不重复问。

“对应客户”是 Excel **“PI论文问题”B5:B16** 的原问题简写，保留单元格位置方便回填。题号按本版访谈顺序重新编排。更新：2026-09-20。

## 60 分钟怎么安排

| 时间 | 内容 |
|---|---|
| 00–02 | 开场：确认参与过的版本、机器人、工作范围和时间 |
| 02–19 | Q1–Q4：路线、语言、长任务、真实失败 |
| 19–35 | Q5–Q7：采集处理、流程演进、新数据 |
| 35–47 | Q8–Q10：架构取舍、能力退化、ICL |
| 47–55 | Q11–Q12：交付、团队与市场 |
| 55–57 | 补齐前面漏答的要点 |
| 57–60 | 复述关键结论，确认哪些仍需核实 |

**控时：** 每题时间包含追问。时间紧就缩短案例和原因展开，保留全部主题；最迟第 47 分钟进入交付与组织问题。回答超出受访者经验范围时，记为待补访谈，不用猜测填满。

## 按顺序问：以下全部必问

<a id="q1"></a>
### ★ Q1 通用模型还是专项适配？｜4 分钟

**对应客户 B7：** “专用模型微调”与“通用模型零样本”，PI 长期怎么选？

**主问：以一个新任务为例，通用模型直接使用与专项适配的差距在哪里？PI 长期希望走向哪种方式？**

**未答到再补齐：** 基座变强后，示范、人工指导和自主练习中，哪项投入下降了？哪项仍省不掉？请区分已经观察到的趋势与未来判断。

<a id="q2"></a>
### ★ Q2 怎样改善语言指令跟随？｜4 分钟

**对应客户 B5：** π0/π0.5 指令跟随不足，π0.7 及后续内部版本做了哪些工程改进？

**主问：针对机器人“看到了东西，却没按指令做”的问题，您接触的版本做过哪些改动，现在还容易错在哪里？**

**未答到再补齐：** 选一次有效改动，说明版本、错误原因和前后结果；怎样区分“没理解指令”和“理解了但动作失败”？

<a id="q3"></a>
### ★ Q3 长任务能稳定做到多长？｜4 分钟

**对应客户 B8：** 可泛化长序列任务的最长时长和动作数量。

**主问：换到新环境后，一个完整任务目前能稳定自主执行多久、大约包含多少步骤？最长验证到什么水平？**

**未答到再补齐：** 最长一次与多次测试的典型水平分别是多少？成功率、测试次数、中途指导或接管情况如何？“动作数量”按语义步骤、动作块还是控制步计算？

<a id="q4"></a>
### ★ Q4 客户现场最常失败什么？｜5 分钟

**对应客户 B14：** 常见失败任务，以及数据、模型、硬件适配的根因判断。

**主问：在您直接了解的 PI 客户场景中，最常失败的前三类任务是什么？主要原因各是什么？**

**未答到再补齐：** 先确认案例来自 PI 项目还是一般行业经验，再问大致频率或排序。选一个案例：补数据、改模型、改硬件分别试过什么，凭什么判断根因？

<a id="q5"></a>
### ★ Q5 数据从采集到入训，怎样保证质量？｜7 分钟

**对应客户 B12：** 遥操作标准、硬件一致性、环境控制，以及自动筛选和预处理。也承接现有“问题建议”中的过滤率与人工标注负担。

**主问：能沿一条真机轨迹，讲清从开始采集到进入训练，必须遵守哪些规范、经过哪些处理吗？**

**未答到再补齐以下三项：**

- **采集规范：** 遥操作员怎么培训和验收？硬件/标定怎样保持一致？环境哪些固定、哪些主动变化？
- **处理规则：** 运动学检查、多摄像头成功验证、视觉归一化分别怎么做，异常怎样处理？确认时间对齐、动作切片的位置，并把固定图像处理与随机增强分开。
- **人工与数量：** 哪些标注和复核仍靠人？原始数据最终剔除多少、入训多少，人工负担大约多大？明确按轨迹数、时长还是人工工时统计。

<a id="q6"></a>
### ★ Q6 数据流程为什么不断改变？｜4 分钟

**对应客户 B13：** 从 π0 到 π0.7，数据处理每次主要调整的驱动和痛点。

**主问：从 π0 到 π0.7，数据流程的主要变化分别是为了解决什么问题？**

**未答到再补齐：** 按主要版本概括“瓶颈—调整—效果”，不展开完整配方。现在最卡的是数量、多样性、标注还是数据配比？如果只能追加一类投入，会选什么，为什么？

<a id="q7"></a>
### ★ Q7 人类视频和触觉，实际怎么用？｜5 分钟

**对应客户 B10：** Ego 第一视角视频、手部触觉的应用，以及缺少机器人本体数据时怎样训练。

**主问：先谈人类第一视角视频，再谈手部触觉：PI 目前分别用到了什么阶段，各解决什么问题？**

**未答到再补齐：**

- **人类视频：** 有哪些标签、让模型预测什么？缺少机器人状态和动作标签时，怎样连接到机器人的动作能力？迁移难点如何处理？
- **触觉/力觉：** 哪类信号已用、试验中或尚未用？用于模型训练输入/监督，还是底层控制？收益和推广瓶颈是什么？未采用时是否有引入计划？

<a id="q8"></a>
### ★ Q8 哪些架构尝试没走通？｜5 分钟

**对应客户 B6：** 从 π0 到 π0.7，被放弃或替代的架构尝试。

**主问：能先列出主要被放弃或暂缓的方案，再选一个您熟悉的例子，说明为什么没继续吗？**

**未答到再补齐：** 哪个版本、训练还是推理阶段、与什么方案比较、主要输在哪里？若提到“放弃离散动作”，确认只指实时解码，还是训练中的离散监督也改变了。

<a id="q9"></a>
### ★ Q9 学新任务会不会损害旧能力？｜4 分钟

**对应客户 B9：** 多任务增加与单任务强化学习，是否分别导致旧任务成功率下降？

**主问：增加训练任务，以及对单一任务做强化学习，这两种更新是否会让原有任务表现下降？**

**未答到再补齐：** 两种情况分别举例或说明尚未观察到。模型规模是否相同？用哪些旧任务复测、怎样防退化？专项策略是否会合回通用模型，合回后如何验证？

<a id="q10"></a>
### ★ Q10 不改权重，能靠示范学新技能吗？｜3 分钟

**对应客户 B11：** PI 对 In-Context Learning（ICL）路线的判断。

**主问：只把几段示范或历史放进上下文、不更新模型权重，目前能学到什么？PI 怎样看这条路线？**

**未答到再补齐：** 是记住进度、纠正当前任务，还是适应新技能？所有组件是否都不改权重？最主要的瓶颈和支持这一判断的实验是什么？

<a id="q11"></a>
### ★ Q11 什么交付模式已验证有效？｜4 分钟

**对应客户 B15：** 为客户训练指定技能，还是更通用的交付，哪种运行比较成功？

**主问：以一个可匿名分享的合作为例，PI 实际交付什么，哪种方式已经运行得比较成功？**

**未答到再补齐：** 采集、适配、硬件接入与运维由谁做？通常需要多少新增数据和多久？“成功”指试点验收、持续使用还是付费续约，哪些已验证？

<a id="q12"></a>
### ★ Q12 团队怎样组织，怎样拓展客户？｜4 分钟

**对应客户 B16：** 学历与产业背景、组织管理架构、营销策略。

**主问：以一项能力从研发走向客户为例，通常哪些团队协作，合作机会又从哪里来？**

**未答到再补齐三项：** ①主要部门/职能、分工与决策方式；②人员学历层次、科研及产业经历的大致构成；③目标客户、主要获客渠道，以及怎样从接触转为持续合作。只了解所在小组时注明范围。

## 遇到这三类回答，怎样追问

| 对方的回答 | 一句追问 |
|---|---|
| “看情况”“提升很大” | “能选一个具体任务，说清改了什么、怎样验证吗？” |
| 给出时长、成功率或占比 | “这是哪一版本、什么条件、多少次测试？比例的分母是什么？” |
| 不方便给数字或细节 | “是否方便给范围、相对排序或匿名案例？不掌握或不便分享的部分我们记为待核实。” |

**收尾检查：** 每题的“对应客户”和“补齐”项是否都有回答？记录为“已答清 / 待核实 / 不掌握 / 不便分享 / 未问到”。12 题在设计上覆盖全部需求；信息是否取得，以实际回答为准。不要用一般行业判断代填 PI 内部事实。

**每题只记一行：** 结论｜版本与案例｜数字及条件｜未答清的要点。最后用 3 分钟复述最重要的判断，请对方校准。
