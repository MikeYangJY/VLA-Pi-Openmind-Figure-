# `examples/aloha_real/constants.py` 中文阅读说明

**定位：** 硬件配置。

保存ALOHA关节名、复位姿态、夹爪标定和时间步等平台常量。

**建议读法：** 先看DT与关节/夹爪归一化常量，再跟踪robot_utils和real_env如何使用。

**易错点：** 这些值对应特定硬件；不要因读懂代码就随意改标定后驱动机器人。
