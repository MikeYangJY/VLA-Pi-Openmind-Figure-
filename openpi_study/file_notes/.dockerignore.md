# `.dockerignore` 中文阅读说明

**定位：** 容器构建过滤。

控制Docker build上下文中不复制哪些文件。

**建议读法：** 与.gitignore作用不同：一个影响容器构建，一个影响Git跟踪。

**易错点：** 格式敏感文件、文档和许可原样保存；中文说明放在本页，避免破坏原格式。
